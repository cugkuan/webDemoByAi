# 日志系统架构

## 系统日志流程

```
┌─────────────────────────────────────────────────────────────────┐
│                    HTTP 请求到达                                   │
└────────────────────────────┬────────────────────────────────────┘
                             │
                             ▼
        ┌────────────────────────────────────┐
        │  loggingMiddleware                 │
        │  记录: REQUEST 进入信息            │
        │  [请求方法, 路径, IP, 时间]        │
        └────────────────────────┬───────────┘
                                 │
                                 ▼
        ┌────────────────────────────────────┐
        │  Handler (getTasks/getTask/...)    │
        │  记录: Handler 开始执行            │
        │  [操作类型, 参数信息]              │
        └────────────────────────┬───────────┘
                                 │
                    ┌────────────┴────────────┐
                    │                         │
                    ▼                         ▼
          ┌─────────────────┐       ┌──────────────────┐
          │ 检查缓存(L1/L2)│       │ 其他业务逻辑     │
          └────────┬────────┘       └──────────────────┘
                   │
         ┌─────────┴─────────┐
         │                   │
    缓存命中              缓存未命中
    ┌──────────┐          ┌──────────┐
    │CACHE HIT │          │CACHE MISS│
    │返回缓存值│          │查询数据库│
    └────┬─────┘          └────┬─────┘
         │                     │
         │              ┌──────▼──────┐
         │              │ DB QUERY    │
         │              │ DB SUCCESS  │
         │              └──────┬──────┘
         │                     │
         │              ┌──────▼──────┐
         │              │ 写入缓存    │
         │              │ L1 + L2     │
         │              └──────┬──────┘
         │                     │
         └─────────┬───────────┘
                   │
                   ▼
        ┌────────────────────────────────────┐
        │  loggingMiddleware (响应)          │
        │  记录: RESPONSE 信息               │
        │  [状态码, 响应时间, 执行时长]      │
        └────────────────────────────────────┘
                   │
                   ▼
        ┌────────────────────────────────────┐
        │  返回 HTTP 响应给客户端            │
        └────────────────────────────────────┘
```

## 缓存操作流程

```
缓存写入流程:
┌─────────────────┐
│  DB 操作返回    │
└────────┬────────┘
         │
    ┌────▼────┐
    │ 设置 L1 │─────► CACHE SET: L1
    └────┬────┘
         │
    ┌────▼────┐
    │ 设置 L2 │─────► CACHE SET: L2
    └─────────┘


缓存失效流程（修改操作）:
┌────────────────────┐
│ CREATE/UPDATE/DEL  │
└────────┬───────────┘
         │
         ▼
    ┌─────────────────┐
    │ 执行数据库操作  │
    └────────┬────────┘
             │
             ▼
    ┌──────────────────────────────┐
    │ CACHE INVALIDATE             │
    │ 清除相关缓存                  │
    └────────┬─────────────────────┘
             │
      ┌──────┴──────┐
      ▼             ▼
   L1 删除        L2 删除
   CACHE DELETE   CACHE DELETE


缓存二级击穿防护:
┌──────────────┐
│ 请求进入     │
└──────┬───────┘
       │
    ┌──▼─────────┐        ┌─────────────┐
    │ 检查 L1    │─Hit──► │返回缓存值   │
    └──┬────┬────┘        └─────────────┘
       │Miss│
       │    └──┐
       ▼       │
    ┌──────────▼──┐       ┌─────────────┐
    │ 检查 L2     │─Hit──► │写回L1       │
    └──┬────┬─────┘       │返回缓存值   │
       │Miss│             └─────────────┘
       │    └──┐
       ▼       │
    ┌─────────▼──┐
    │ 查询数据库 │
    └──┬─────┬───┘
       │     │
    ┌──▼──▼──┐
    │写入L1+L2│
    └────────┘
```

## 错误处理流程

```
异常发生
   │
   ▼
┌─────────────────┐
│ 记录 ERROR: 日志 │
│ [错误类型,原因]  │
└────────┬────────┘
         │
         ▼
┌─────────────────────────────┐
│ 返回错误响应                 │
│ [状态码, 错误消息]           │
└────────┬────────────────────┘
         │
         ▼
┌─────────────────────────────┐
│ loggingMiddleware 记录       │
│ RESPONSE: 错误状态码         │
└─────────────────────────────┘
```

## 数据库操作日志矩阵

```
┌──────────┬──────────────────┬──────────────┬────────────────────┐
│ 操作类型 │  操作日志        │  查询日志    │  结果日志           │
├──────────┼──────────────────┼──────────────┼────────────────────┤
│ SELECT   │ DB QUERY         │ SQL内容      │ DB SUCCESS: 记录数  │
│ INSERT   │ DB CREATE        │ 参数信息     │ DB SUCCESS: ID      │
│ UPDATE   │ DB UPDATE        │ ID+字段      │ DB SUCCESS: ID      │
│ DELETE   │ DB DELETE        │ ID           │ DB SUCCESS: ID      │
│ 错误     │ ERROR: DB操作    │ 详细错误     │ N/A                 │
└──────────┴──────────────────┴──────────────┴────────────────────┘
```

## 后台清理任务日志

```
系统启动
   │
   ▼
启动清理 goroutine
   │
   ▼
┌──────────────────┐
│ 每分钟执行一次   │
└─────────┬────────┘
          │
    ┌─────▼─────────┐
    │ 遍历L1缓存     │
    │ 检查是否过期   │
    └─────┬─────────┘
          │
    ┌─────▼──────────────┐
    │ 找到过期项         │
    │ 删除               │
    │ CLEANUP: 清理N项  │
    └────────────────────┘
```

## 性能影响分析

```
日志操作耗时对比:

┌────────────────────┬──────────┬────────────────────┐
│ 操作类型            │ 耗时     │ 对总耗时的影响      │
├────────────────────┼──────────┼────────────────────┤
│ 写入单条日志        │ 0.05ms   │ ~0.5-1%            │
│ 格式化字符串        │ 0.02ms   │ ~0.2-0.5%          │
│ 写入磁盘(异步)      │ 几毫秒   │ 可忽略(后台任务)   │
│ 缓存命中响应        │ 2-5ms    │ 主导时间           │
│ 数据库查询          │ 10-50ms  │ 主导时间           │
└────────────────────┴──────────┴────────────────────┘

结论: 日志开销很小(<5%), 主要耗时来自缓存+数据库
```
